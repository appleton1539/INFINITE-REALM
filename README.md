# INFINITE REALM｜無限輪迴

《INFINITE REALM／無限輪迴》TRPG 平台前端原型。

## 使用方式

本專案目前為靜態單頁網站，入口為 `index.html`。可透過 GitHub Pages 發布。

## 目前功能

- 世界背景與無限管理局設定摘要
- 角色資料表與八項屬性 27 點購點草案
- 角色草稿儲存於瀏覽器 localStorage
- 角色資料匯出 JSON
- 預設劇本資料庫
- 劇本投稿草稿（本機 localStorage）
- 依難度區間與類型隨機抽取劇本
- 法術書 Excel 外部連結（OneDrive）

## 重要限制

此版本尚未包含帳號登入、雲端資料庫、多玩家同步、線上投稿審核、GM 權限系統或 AI GM。角色規則中的購點表為目前可確認的原型草案；V1.4 戰鬥、HP／MP 與傷害公式尚未整合。請以正式規則文件為準。

在 Repository 的 **Settings → Pages** 中，將 Build and deployment 設為 **Deploy from a branch**，Branch 選 `main`，資料夾選 `/(root)`，再按 Save。
